# Media URL Copy for X

Android版Xの画像・動画の配信URL（twimg.com）をコピーするための、Morphe用パッチです。

**このソースにはコピー用のパッチ1個だけを含みます。PikoやNagi Explorerは必要ありません。** ダウンロード・フォルダ保存・GIF変換機能は含みません。

## 機能

次の3か所に「メディアURLをコピー」を追加します。

1. ポスト上の画像・動画の長押しメニュー。
2. 画像・動画を開いてから長押ししたときのメニュー。
3. 画像・動画を開いた画面の右上の三点メニュー。

- 複数画像は選択した画像、ビューアーはスワイプ後の画像が対象です。
- 画像は画像URL、動画・GIF画像はMP4/WebMの配信URLをコピーします。
- 動画に複数の解像度がある場合は選べます。HLSプレイリストは対象外です。
- コピーするURLの `?` 以降は取り除きます。
- 画像や動画のダウンロードは行いません。

例:

```text
https://video.twimg.com/example.mp4?tag=12
↓
https://video.twimg.com/example.mp4
```

## 対応環境

- X: **12.19.1-release.0**、パッケージ `com.twitter.android`
- Android 8.0以上
- Morphe Patcher 2.0.1に対応したパッチ適用環境

X内部のクラス・フィールドに依存するため、ほかのXバージョンへの対応は保証しません。パッチ適用時に対象のフィールド構成をチェックします。

## 使い方

1. Releasesから `media-url-copy-0.1.0.mpp` を取得します。
2. Morpheでローカルのパッチソースとして読み込みます。
3. **未改変のX 12.19.1-release.0のAPK/APKM** を入力に選びます。
4. `Copy media URL` を選択してパッチを適用し、署名・インストールします。

既存アプリを更新する場合は同じ署名鍵が必要です。このリポジトリではX本体のAPKや署名鍵を配布しません。

旧Media Save Labには同じコピー機能が含まれます。旧Media Save Labとの同時適用はしないでください。ほかのパッチ集との組み合わせは実機未検証です。
